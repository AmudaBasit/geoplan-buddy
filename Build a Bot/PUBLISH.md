# Publish and submit GeoPlan Buddy

## Using GitHub Desktop
1. Open GitHub Desktop and sign in to your GitHub account.
2. Choose File > Add local repository. Select the **Build a Bot** folder that contains this file and its existing .git directory. Do not create a nested repository.
3. Review the changed files. Only publish material intended for public viewing. This project does not need the instructor's PDF uploaded.
4. Commit the project files with a message such as `Add GeoPlan Buddy prototype and lab evidence`.
5. Choose Publish repository. Use a suitable name such as `geoplan-buddy`. For free GitHub Pages hosting, use a public repository if your account's plan requires it. Review the visibility before confirming.
6. Open the repository on GitHub. Go to Settings > Pages. Under Build and deployment, choose Deploy from a branch. Select the branch containing the committed files and the `/docs` folder, then Save.
7. Wait for the Pages deployment to finish. Copy the actual URL shown in Settings > Pages; do not assume a URL is active before GitHub confirms it.
8. Open that URL in a signed-out/private browser window and check all links.

If GitHub Desktop is unavailable, install it from the official GitHub Desktop site or use GitHub's web interface to upload the prepared files, preserving their folder structure.

## What the links mean
- Repository URL: source, instructions, tests, and documentation.
- Pages URL: readable project demonstration and prototype evidence.
- Neither URL is a hosted generative chatbot. Reviewers can run the instructions in their own ChatGPT session.

- Save actual conversations/screenshots as evidence, removing personal information.
