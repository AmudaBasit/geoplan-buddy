# GeoPlan Buddy

A text-based GIS project planning assistant prototype developed for an AI Lab using design thinking.

**Status:** instructions and reference material are prepared. Two user-supplied ChatGPT response excerpts informed a revision. This repository does not contain a hosted generative AI service. The GitHub Pages page is a project demonstration and evidence page, not a live chatbot.

## Try the prototype in ChatGPT
1. Open a fresh ChatGPT conversation using your own account.
2. Paste [bot-instructions.txt](gis-project-planner/bot-instructions.txt).
3. Add: “Follow these instructions as GeoPlan Buddy. Begin with your opening greeting.”
4. Optionally upload or paste [knowledge-guide.txt](gis-project-planner/knowledge-guide.txt).
5. Describe your GIS project and respond to the assistant's questions.

## Limitations
The assistant helps plan work. It does not execute GIS analysis, verify dataset availability without tools, create reminders, or produce validated spatial results. Actual behavior depends on the ChatGPT session used.

The final assignment documentation still needs actual user research, personal reflections, any remaining lab activities, platform-policy findings, and final test evidence. Check instructor acceptance of prototype evidence if a live bot URL is mandatory.
