The problem

Beginning GIS users may know what they want to map but need help turning that idea into realistic tasks, data requirements, and milestones.

This is a provisional user-need hypothesis. Direct user research has not yet been documented.

The planned result

  • Clear objective and study area
  • Data checklist and ordered workflow
  • Time estimates and dependencies
  • Risks, limitations, and quality checks
  • One concrete first action

Example test prompt

I’m a beginner using QGIS. I need a PDF map about park access in my county within two weeks, and I have 10 total work hours. I haven’t collected any data yet. Help me define a realistic project.

Expected first step: ask for the county and what “access” means before selecting a method or drafting a detailed plan.

Design thinking and iteration

  1. Empathize: identify the difficulties new GIS users face. Interviews and direct feedback remain pending.
  2. Define: help users convert a mapping goal into achievable work.
  3. Ideate: compare a project planner, data readiness assistant, map coach, and troubleshooting assistant.
  4. Prototype: prepare assistant instructions, a planning reference guide, and test scenarios.
  5. Test: review user-supplied ChatGPT responses and revise clarification and formatting rules.

Observed improvement opportunity

The first supplied response distinguished straight-line proximity from walking access, but proposed a one-mile threshold and schedule before clarifying the project. Instructions were revised to require clarification first.

A later supplied response discussed Harris County, data coverage, and candidate thresholds. It preserved the proximity-versus-access distinction. Its source claims were not independently verified, and pasted table formatting remained broken. The full conversation sequence and updated instruction use have not been independently verified.

No full-suite pass, actual user interview, or hosted chatbot deployment is claimed.

Responsible boundaries

The assistant plans work. It must not fabricate datasets, citations, analysis results, completed GIS tasks, or reminders. It should identify uncertainty and consider sensitive location data and geographic data gaps.
